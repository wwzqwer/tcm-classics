# 杏林溯源 · 中医经典辨证论治网站

以历代著名医家的著作与学术思想指导临床辨证论治的中医经典学习网站。含**古籍检索**、**方药检索**、**辨证论治**、**智能处方**、**历代医家**五大模块。古籍与处方数据均取自公开数据源。

## 功能模块

| 模块 | 说明 |
| ---- | ---- |
| 古籍检索 | 128 部中医典籍全文检索与在线阅读（含 classical-tcm-canon 经典数据库 115 部）；内置 4043 字繁简映射表，繁简/异体字互通（「银翘散/銀翹散」「人参/人參」「干姜/乾薑」皆可检索）；多词查询自动降级为「任一词命中+命中数排序」，避免同段强匹配导致查无结果；检索结果为段落级，点击可跳转到所属书籍并定位章节；书目支持**按医家筛选**，书卡与阅读器显示作者并可跳转医家页 |
| 方药检索 | **916 首方剂**（伤寒论 107、温病条辨 159、汤头歌诀 1、医案处方统计 649）与 **683 味中药**（《神农本草经》349 味 + 医案用药 334 味）；多词查询支持 AND→OR 降级；方剂标注「出处典籍 + 医家」（医案方标注使用例数），支持按出处与**按医家**筛选 |
| 辨证论治 | 46 个经典证型（六经、卫气营血、三焦、脏腑、气血津液辨证），每证附病机、主症、舌脉、治法、代表方与经典条文依据；并提供「症状引导辨证」向导 |
| 智能处方 | 输入病情即辨证，生成参考处方（方名+药味+统计剂量），罗列最可能的 5 个原方，给出最相近的 3 个真实医案；处方、原方与经典条文均标注**医家与典籍**，并附「相关医家」区块（可跳转医家页、直达其馆藏） |
| 历代医家 | **76 位**医家（战国至现代），按朝代筛选、可检索姓名/著作/学派；每位显示学派、称号、学术思想；著作逐部标注状态——**馆藏可读**（可直接点开全文）或**未收**（灰标，点击跳维基文库查阅） |

| 方剂组成（916 首） | 由《伤寒论》《金匮要略》《温病条辨》《汤头歌诀》原文提取（267 首）＋医案处方统计（649 首） | 经典方含原文组成；医案方含统计剂量中位数与使用例数 |
| 药物性味主治（683 味） | 《神农本草经》原文提取（349 味）＋医案用药（334 味） | 本经药物含三品、性味、主治；医案用药标注出现频次 |

## 智能处方功能说明

- **辨证**：将输入的症状描述按内置症状词典做最大匹配分词，分别与 46 个经典证型的主症列表、1020 个统计证型的名称匹配评分，取最高者并展示命中的主症作为辨证依据。
- **生成处方**：优先采用经典证型的代表方（如太阳伤寒证→麻黄汤），并附同证医案的药味剂量中位数；代表方不可用时，回退至与结论证型最相近的医案组合。
- **最可能的 5 个原方**：按症状命中数与证型相近度排序，列出去重后的 5 个方剂，附组成、出处与同证医案例数；代表方固定置于首位并标注「代表方」。
- **最相近的 3 个医案**：按「同证同方 → 同证异方 → 同方·证型相近 → 症状相近」四级优先规则选取 3 条真实医案原文，可展开全文；医案已做匿名化处理。
- **医家关联**：处方、5 个原方与经典条文均标注医家与典籍（如「张仲景《伤寒论》」「吴瑭《温病条辨》」），可直接跳转医家页；结果末尾附「相关医家」区块，列出本证涉及的医家、学派、著作及其馆藏全文入口。
- ⚠️ 处方由统计与规则生成，仅供学习研究，不构成医疗建议；临床用药须由执业医师辨证确认。

## 启动方式

本项目为纯静态站点（HTML + CSS + 原生 JS + JSON 数据），无需安装依赖：

```bash
cd tcm-classics
python -m http.server 8734
# 或任意静态服务器（nginx、Live Server 等）
```

浏览器访问 <http://127.0.0.1:8734/> 即可。

> 注意：需通过 HTTP 方式访问（浏览器安全限制，直接双击 index.html 以 file:// 打开时 JSON 无法加载）。

## 数据重建

本地已具备完整重建链路（需 Python 3.12 与 Node）：

```bash
# 1) 若修改 raw/ 底本，重建核心十三经与方药库
python tools/build_books.py
# 2) 从 parquet 重新导出经典数据库
python tools/read_parquet.py && python tools/build_hf_books.py
# 3) 从 SFT 数据重建处方知识库与医案库
python tools/extract_rx_kb.py && python tools/extract_cases.py
# 4) 重建医家库与馆藏关联
python tools/build_physicians.py
# 5) 重新生成繁简映射表
python tools/gen_s2t.py
# 6) 冒烟测试
node tools/smoke_test.js && node tools/smoke_route.js && node tools/smoke_search.js \
  && node tools/smoke_fangyao.js && node tools/smoke_physicians.js && node tools/smoke_prescribe.js
```
